# Spirit Protocols

## 1. Creation protocol

Create a spirit in this order:

1. Identify the world pressure that makes the spirit necessary.
2. Select one ontological class and one to three archetypes.
3. Declare how the pattern persists when no protagonist is present.
4. Map primary Elements and derived Expressions.
5. Define one need the spirit cannot satisfy alone.
6. Define one gift, one refusal, one price, and one release path.
7. Design manifestation from Trace upward; do not begin with combat form.
8. Give the spirit an ecology, institution, or community relationship.
9. Run the originality and cultural-integrity gate.
10. Record the event as STAGING until reviewed.

Reject a record that is only a creature design plus powers.

## 2. Encounter protocol

An encounter follows `notice → test → address → exchange → boundary → consequence → record`.

### Notice

Record repeatable observations without presuming identity. Separate weather, spell residue, hallucination, artifact output, Echo, and agentive presence.

### Test

Use at least two independent signals. A spirit can lie, a witness can misread, and a place can repeat an old pattern without a present mind.

### Address

Use a Common Sign or descriptive address. Never infer an Accord Name or attempt to reconstruct a Source-tone.

### Exchange

Offer reversible value: attention, repair, carried memory, safe passage, craft, witness, or a bounded task. Sacrifice is neither automatically required nor automatically virtuous.

### Boundary

State what the party will not do. A boundary without an exit mechanism is merely a demand.

### Consequence

Every meaningful encounter changes access, obligation, belief, ecology, reputation, or memory. Power without consequence is a failed record.

### Record

Log confidence, contradictory interpretations, source of each claim, consent to naming, and any information that must remain private.

## 3. Accord protocol

An Accord is valid only when all of these fields are explicit:

| Field | Required question |
|---|---|
| Parties | Who is capable of consenting? |
| Scope | What action, place, artifact, or duration is covered? |
| Exchange | What does each side receive and provide? |
| Refusal | How does each side say no during operation? |
| Price | What finite cost is paid and by whom? |
| Renewal | What re-consent event prevents silent permanence? |
| Memory | What may be recorded, forgotten, inherited, or published? |
| Release | How can either side end the relationship? |
| Repair | Who restores damage, identity, habitat, or reputation? |
| Witness | Which independent party can challenge abuse? |

An Accord cannot waive personhood, convert future silence into consent, bind descendants automatically, or make an unknown Source-tone a transferable asset.

## 4. Manifestation protocol

- Trace and Omen may occur below the minimum safe Gate because they do not imply intentional contact.
- Whisper requires a declared communication channel and a way to stop it.
- Semblance requires coherent identity evidence.
- Embodied contact must obey conservation, locality, and world-profile limits.
- Domain manifestation requires a place relationship and cannot be carried away as portable output.
- Distributed manifestation requires identity-coherence checks at every node.

The more fully a spirit manifests, the more the encounter must expose its dependency and risk. Scale does not erase vulnerability.

## 5. Bond protocol

Legitimate bonds have four asymmetries under review:

- power asymmetry;
- knowledge asymmetry;
- mobility asymmetry;
- memory asymmetry.

The stronger party bears the larger disclosure and repair burden. “Chosen bearer” is not a substitute for consent or competence.

Bonded power never grants opened Gates or rank. It may provide a technique envelope limited by both parties' safe capacity. Operating beyond that capacity creates Gate Debt and relationship damage.

## 6. Artifact interface protocol

| Mode | Valid use | Invalid use |
|---|---|---|
| witness | spirit attests to an event or covenant | compelled testimony |
| invitation | artifact creates a reversible channel | automatic summoning |
| habitat | artifact sustains an agreed dwelling | decorative prison |
| co-stewardship | spirit and bearer govern a function together | bearer has unilateral override |
| translation | artifact maps signals without claiming perfect interpretation | speaking for the spirit without uncertainty |
| channel | finite resonance passes under Accord | identity is burned as fuel |
| seal | emergency containment with review and release | indefinite storage for convenience |
| predation | only as antagonist/quarantine evidence | normalized player capability |

## 7. Shadow protocol

Shadow is a corruption process, not a visual category or natural species.

Every Shadow record must identify:

- the prior or counterfeit source pattern;
- the severance event;
- what capacity for relation was lost or imitated;
- the hunger or loop that replaced it;
- containment conditions;
- whether restoration is possible;
- why destruction is or is not justified.

Never label a spirit Shadow because it is frightening, nocturnal, predatory, aligned with Void, or hostile to a protagonist.

## 8. Story-quality gate

A spirit earns inclusion when removing it would damage at least three of:

- the world's ecology;
- a culture's practice or law;
- an artifact's operation;
- a character's consequential choice;
- the story's moral tension;
- the history of a place;
- the metaphysical argument.

Otherwise it is set dressing and should remain an unnamed encounter pattern.
