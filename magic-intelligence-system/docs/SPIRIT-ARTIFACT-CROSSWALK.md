# Spirit–Artifact Crosswalk

Status: STAGING

Artifacts can mediate relationships with spirit-beings. They cannot reduce a spirit to fuel, inventory, or a spell effect.

## Bond modes

| Mode | Artifact function | Required safeguard |
|---|---|---|
| witness | records that an exchange occurred | both parties can contest the record |
| invitation | makes contact possible | invitation expires and can be refused |
| habitat | sustains a chosen manifestation | exit remains possible |
| co-stewardship | shares care of a place or process | duties and repair are mutual |
| translation | renders signs mutually legible | uncertainty and mistranslation remain visible |
| channel | carries a bounded capability | limits, price, duration, and shutdown are explicit |
| seal | contains an immediate threat | review, appeal, repair, and release conditions are mandatory |
| predation | coerces, fragments, consumes, or imprisons | quarantined; never a normal player capability |

Pact-class artifacts use an Accord; the artifact is not itself the relationship. Vessels and Engines with agency retain refusal and transfer rights. A Key can open a contact boundary but cannot summon a specific being without consent.

## Capability boundary

A spirit bond may grant one negotiated expression of capability. It never grants:

- opened Gates or rank;
- a spirit's full identity, memory, culture, or domain authority;
- permanent ownership of the spirit;
- immunity from the artifact's price or the spirit's boundary;
- permission to bind other beings of the same class.

The wielder remains responsible for discipline, consent, and consequences.

## State model

| Bond state | Meaning | Projection |
|---|---|---|
| proposed | terms offered, not accepted | no capability |
| accorded | bounded terms mutually accepted | allowed when both endpoints project |
| strained | boundary or duty contested | warning required |
| suspended | interaction paused pending repair | capability disabled |
| released | accord ended and obligations settled | historical record only |
| breached | a party violated terms | remediation workflow |
| predatory | coercion or severance detected | quarantine |

Every bond record identifies need, consent protocol, capability boundary, price, breach consequence, release condition, and repair path.

## Existing seed integration

The seed crosswalk pairs original STAGING spirits with the ten artifact records without rewriting the artifacts' primary designs. Examples include:

- Sovaelin using Aeralith as an invitation to unfinished routes;
- Brannovar co-stewarding Rootwake's living system;
- Mirevael translating contextual memory through Mnemora;
- Cyrentha witnessing bounded vows through Cinder-Vow;
- Drauvoss preying through the quarantined Selka Hollow-Mask.

These are relationship records, not retroactive canon. Each must survive artifact validation, spirit validation, rights review, and human approval.
