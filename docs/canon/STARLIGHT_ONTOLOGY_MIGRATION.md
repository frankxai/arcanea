# Starlight–Arcanea ontology migration

Status: proposal for human canon review. No locked Arcanea decision is silently overridden.

## Boundary decision

- Starlight is stellar light and the governed metaphor of benevolent transmission. It is not an Arcanean deity, species, or metaphysical force.
- Arcanea is fiction. Its beings, ranks, magic, frequencies, and cosmology do not explain real religions or established physics.
- The Arcanean Source is a fictional abstraction: unnamed, unknowable, and beyond representation. It is not an equation among God, Tao, Brahman, Ein Sof, Logos, Dharmakaya, or other tradition-specific concepts.
- Lumina is First Light within Arcanea fiction. Lumina is not Starlight.
- Shinkami is an Arcanean being and gate figure, not a real-world ultimate.
- The Field is fictional magic-world substrate, not a scientific claim.

## Unresolved decision: Arcanea canon authority

The brief names `arcanea-lore/CANON.md` as canonical. Existing repository governance instead names `.arcanea/lore/CANON_LOCKED.md`; `.claude/CANONICAL_AUDIT.md` names `.claude/lore/ARCANEA_CANON.md`. This PR corrects the requested file but does not demote either competing authority. Merge only after one authority and mirror policy are explicitly chosen.

Recommended resolution: `.arcanea/lore/CANON_LOCKED.md` remains the compact approved truth ledger; `arcanea-lore/CANON.md` becomes the public narrative canon derived from it; `.claude/lore/ARCANEA_CANON.md` becomes a generated agent projection. The alternative—making `arcanea-lore/CANON.md` primary—is valid only when CI verifies both mirrors are derived and cannot drift.
